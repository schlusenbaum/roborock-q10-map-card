# Roborock Q10 Map Card

Lovelace Map Card for the Roborock Q10.

## Installation

Install via HACS as a Lovelace plugin.

After installation, add the following resource to Home Assistant:

url: /hacsfiles/roborock-q10-map-card/roborock-q10-map-card.js
type: module

## Features

- Roborock Q10 map
- Room names and room IDs
- Room cleaning selection
- Room icons
- Mirrored map correction
- Custom room names

## Requirements

- Home Assistant
- Roborock Q10 integration
- Xiaomi Vacuum Map Card
